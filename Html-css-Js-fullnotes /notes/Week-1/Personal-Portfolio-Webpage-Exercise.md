# Exercise: Build a Personal Portfolio Webpage

## Objective

Create a personal portfolio webpage using **HTML only**.

This project will help you practice:

- Headings
- Paragraphs
- Images
- Links
- Lists
- Tables
- Forms

**Do not use CSS.** Focus on writing clean HTML.

---

## Project Requirements

### 1. Create the HTML Document

Create an `index.html` file with the correct HTML structure.

Set the page title:

**My Portfolio**

---

### 2. Introduction

At the top of your page include:

- Your full name using an `<h1>`
- Your career title using an `<h2>`
- A short introduction paragraph
- Your profile picture

#### Example:

```
John Doe

Junior Web Developer

"I am a software engineering student passionate about building websites and learning new technologies."
```

---

### 3. Page Navigation

Create an unordered list that links to different parts of your webpage.

Your menu should include:

- About Me
- Skills
- Education
- Projects
- Contact

#### Example:

```
• About Me
• Skills
• Education
• Projects
• Contact
```

The links should move the user to the correct part of the page.

---

### 4. About Me

Create an **About Me** section.

Include:

- Your picture
- Two paragraphs describing yourself

Your description can include:

- Your background
- Why you are learning programming
- Your career goals

#### Example:

```
My name is Sarah. I am currently learning web development.

My goal is to become a software developer and build useful applications.
```

---

### 5. Skills

Create a list of your skills.

#### Requirements:

- Create an **unordered list** with at least **8 skills**.
- Create an **ordered list** showing **5 technologies** you want to learn next.

#### Example:

**Skills:**

- HTML
- CSS
- JavaScript
- Git
- Communication

**Technologies to learn:**

1. React
2. Node.js
3. SQL
4. Docker
5. Cloud Computing

---

### 6. Education

Create a table showing your education history.

Your table should contain:

| Institution | Course | Year |
|-------------|--------|------|

#### Example:

| Institution | Course | Year |
|-------------|--------|------|
| Makerere University | Software Engineering | 2026 |
| ABC High School | Science | 2022 |

Include at least **3 records**.

---

### 7. Projects

Create a table showing projects you have worked on or would like to build.

Your table should contain:

| Project | Description | Status |
|---------|-------------|--------|

#### Example:

| Project | Description | Status |
|---------|-------------|--------|
| Portfolio Website | My personal website | Completed |
| Calculator App | Simple calculator using JavaScript | In Progress |

Include at least **4 projects**.

---

### 8. Useful Websites

Create a list of useful websites with clickable links.

Include:

- GitHub
- MDN Web Docs
- W3Schools
- Stack Overflow

#### Example:

- GitHub
- MDN Web Docs
- W3Schools

All links should open in a **new browser tab**.

---

### 9. Contact Form

Create a form that allows visitors to contact you.

Your form should include:

#### Text Inputs

- Full Name
- Email Address

#### Radio Buttons

Example:

**Gender:**

- ( ) Male
- ( ) Female

#### Checkboxes

Example:

**Interested Technologies:**

- ☐ HTML
- ☐ CSS
- ☐ JavaScript
- ☐ Python

#### Dropdown List

Example:

**Reason for Contact:**

- [ Internship Opportunity ]
- [ General Inquiry ]
- [ Collaboration ]

#### Message Box

Allow users to type a longer message.

#### Buttons

Include:

- Submit button
- Reset button

---

### 10. Contact Information

At the bottom of your page include:

- Email address
- Phone number
- GitHub profile link
- LinkedIn profile link

#### Example:

```
Email: john@example.com

GitHub: github.com/johndoe

LinkedIn: linkedin.com/in/johndoe
```

## Tips

- Use `id` attributes on sections and `href="#section-id"` for navigation links.
- Always include meaningful `alt` text for images.
- Use `target="_blank"` so external links open in a new tab.
- Use `rel="noopener"` with `target="_blank"` for safer external links.
- Keep your HTML neat and indented so it is easy to read.
